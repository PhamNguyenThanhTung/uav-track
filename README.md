# UAV Simulation Project

This project contains simulation models, configurations, and documentation for custom UAV simulation with ROS 2 Jazzy, Gazebo Harmonic, and PX4.

```text
│   │       └── model.sdf
│   ├── worlds/

│   └── run_sim_phase1.sh
├── config/
│   └── sim/

└── README.md
```
